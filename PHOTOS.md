# Janath Cargo website — photo slots

Each image on the site is a slot. Until a photo is added, the slot shows a Janath-coloured illustration.

**To add a photo:** save a JPG into `site/assets/photos/` with the exact file name below and push. The page picks it up automatically and the illustration disappears. No code changes.

Add `?slots` to the page address (for example `/?slots`) to see each slot's number on the page.

## Rules

- Use photos Janath Cargo owns, or images licensed for commercial use.
- Don't present stock or illustrative images as Janath Cargo's own staff, vehicles, warehouse, customers or deliveries.
- Export as JPG, quality around 80, ideally under 400 KB each.
